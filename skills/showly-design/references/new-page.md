# New pages and requested redesigns

Adapted from Impeccable; see [source record](upstream.md).

Choose a composition for the visitor's task. A landing page needs a clear reason
to act; an application needs efficient task completion; an article needs sustained
readability; a portfolio should foreground the work. A product can contain all
of these surfaces without using the same layout for each.

Identify the strongest supplied content and let it lead. Establish a clear first
reading point, a deliberate type hierarchy, a consistent spacing scale and a
limited set of semantic colors. Explain an important design choice briefly when
it helps the user assess the result. Do not require a fixed menu of aesthetics.

Use real provided imagery when it matters to the brief. Preserve its aspect ratio
and reserve its dimensions to avoid layout shift. If a required asset is missing,
make that gap explicit rather than fabricating evidence or substituting a made-up
customer logo. Decorative assets must not masquerade as product screenshots.

Match density to the task: comparison tools can be dense; a focused invitation
can be sparse. Group related elements and separate distinct topics. Use asymmetry,
large type or expressive color when the content and brief support it. Quiet pages
can be distinctive through precise typography and strong content alone.

Give the primary action a clear label and a working destination. For forms and
interactive controls, implement realistic empty, loading, error and success states
where needed. Do not attach fake success behavior to an unconnected form; explain
what remains to connect. Keep basic content and actions usable without animation.

Reuse the existing stack and component library. Do not install a new framework,
animation library or design system merely because a visual reference resembles it.
During a redesign, preserve routes, data, integrations and required behavior even
when the requested appearance changes substantially.
