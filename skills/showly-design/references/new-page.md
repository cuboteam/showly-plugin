# New pages and requested redesigns

Adapted from Impeccable; see [source record](upstream.md).

Choose a composition for the visitor's task. A landing page needs a clear reason
to act; an application needs efficient task completion; an article needs sustained
readability; a portfolio should foreground the work. A product can contain all
of these surfaces without using the same layout for each.

Identify the strongest supplied content and let it lead. Establish a clear first
reading point, a deliberate type hierarchy, a consistent spacing scale and a
limited set of semantic colors. Explain an important design choice briefly when
it helps the user assess the result. Do not require a fixed menu of aesthetics.

## Turn brand character into visible choices

For an expressive page or redesign, infer a compact direction from the brief:
who it is for, how it should feel, and which content deserves the first look.
Translate that direction into composition, type, image treatment and interaction,
rather than changing only the accent color. A sociable cafe, a remote retreat and
a live music series should not become the same split hero with different names.
Use these as examples of distinct intent, not as prescribed styles by industry.

Choose a recognizable visual idea and carry it through the page: an editorial
image sequence, a poster-like type hierarchy, a useful dense index, or another
composition supported by the material. Minimalism is a choice, not the default
meaning of “tasteful.” Strong color, scale, overlap or asymmetry can be appropriate;
keep reading order, contrast and actions clear. Do not force expressive branding
onto an existing utility interface when the request is only a small refinement.

## Make imagery part of the composition

Use supplied real imagery when available. When the brief calls for photographs
and permits sourcing, use available image-search or asset tools to find suitable
real photos, check their source and usage terms, and retain attribution. Do not
stop at empty boxes merely because the user did not attach images. If sourcing
is unavailable or an exact product/property image is required, state the gap.
Stock photos can illustrate a mood; do not present them as the actual venue,
product, customer or event. Generated images are not real photography evidence.

Inspect image content before choosing crop, focal point and text placement.
Reserve image dimensions to avoid layout shift; preserve natural proportions
unless a deliberate cover crop improves composition without losing the subject.
Check the crop again on mobile. Use stable contrast for overlaid text and useful
alt text. Replacing an empty rectangle with a photo is not by itself a redesign.

For briefs seeking a distinctive identity, ask whether removing the brand name
would leave the page interchangeable with unrelated projects. If so, revisit a
meaningful composition or content choice within scope, rather than adding random
decoration. Familiar conventions remain appropriate when they serve the task. Compare visual character
as well as overflow and functionality during the existing browser review.

Match density to the task: comparison tools can be dense; a focused invitation
can be sparse. Group related elements and separate distinct topics. Use asymmetry,
large type or expressive color when the content and brief support it. Quiet pages
can be distinctive through precise typography and strong content alone.

Give the primary action a clear label and a working destination. For forms and
interactive controls, implement realistic empty, loading, error and success states
where needed. Do not attach fake success behavior to an unconnected form; explain
what remains to connect. Keep basic content and actions usable without animation.

Reuse the existing stack and component library. Do not install a new framework,
animation library or design system merely because a visual reference resembles it.
During a redesign, preserve routes, data, integrations and required behavior even
when the requested appearance changes substantially.
