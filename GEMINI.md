# Showly

Use the instructions in `skills/showly-hosting/SKILL.md` whenever the user asks to host, preview, publish, share, update, or manage a website with Showly. Connect to the configured `showly` MCP server and follow its OAuth flow. Treat a generic deploy request as a protected unpublished version at the site's stable Showly URL; publish only after the user explicitly asks and completes the tool's confirmation flow. Use separate Preview/Live wording only when the site's advanced deployment controls are enabled.
